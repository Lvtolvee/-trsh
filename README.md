# Пышкинские традиции — редизайн сайта

Концепции редизайна [pishkaexclusive.ru](https://pishkaexclusive.ru/) (кулинария КулинарМаркет Эксклюзив, Уфа).
Откройте `index.html` в браузере.

## Раунд 2 — десктоп, статусный стиль (`layouts/v2`)

| № | Файл | Концепция |
|---|------|-----------|
| 1 | `1-emerald.html` | **Изумруд** — развитие фирменного зелёного: изумруд + золото, антиква Cormorant. Мега-меню на 17 разделов, мозаика категорий, карточки с ценой за 100 г и средним весом, бонусная карта, калькулятор фуршета, контакты с картой |
| 2 | `2-graphite.html` | **Графит** — строгий магазин: левый сайдбар-каталог (как на текущем сайте, но аккуратнее), винный акцент из логотипа, редакционный блок, пакеты фуршета «Кофе-брейк / Классический / Банкет» |
| 3 | `3-linen.html` | **Лён** — светлый и воздушный: полноэкранное фото, поиск с выбором раздела и времени доставки, все 17 разделов кругами, подборки по поводам, отзывы, бонусы |

Общие данные (разделы, товары, контакты) — в `layouts/v2/data.js`.

### Фото
Сейчас стоят временные фото с Unsplash (подгружаются из интернета). Если фото не загрузилось, показывается фирменная подложка.
Заменить на свои: положить фото из `public_html/image/...` рядом и поправить ссылки в `data.js` (объекты `HERO`, `CATS`, `PRODUCTS`).

### Что проверить
Телефоны, адрес, график и названия разделов взяты с текущего сайта. Цены за 100 г, проценты бонусов, стоимость фуршета и отзывы — **примерные**, заменить на реальные.
