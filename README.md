# Пышкинские традиции — редизайн сайта

Три концепции макета для [pishkaexclusive.ru](https://pishkaexclusive.ru/) (кулинария и доставка в Уфе).

Откройте `index.html` в браузере: оттуда есть ссылки на все три варианта.

| № | Файл | Концепция |
|---|------|-----------|
| 1 | `layouts/1-noir.html` | **Noir**: тёмный премиум, золото, bento-сетка категорий, крупная гротескная типографика, бегущая строка |
| 2 | `layouts/2-heritage.html` | **Heritage**: светлая журнальная вёрстка, антиква Playfair, терракота и изумруд, национальный орнамент, меню-прейскурант |
| 3 | `layouts/3-fresh.html` | **Fresh**: яркий food-tech в духе приложений доставки, фильтр по категориям, рабочая корзина, калькулятор фуршета |

Все макеты адаптивные (десктоп и мобильные), написаны на чистых HTML/CSS/JS без сборки.

Иллюстрации блюд — векторные заглушки, их заменят реальные фото. Цены, рейтинги и отзывы — примерные, их нужно сверить с актуальным каталогом.
